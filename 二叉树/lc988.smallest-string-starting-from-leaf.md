# lc988.smallest-string-starting-from-leaf

- 概念：lc988.smallest-string-starting-from-leaf
- 给定一颗根结点为 `root` 的二叉树，树中的每一个结点都有一个 `[0, 25]` 范围内的值，分别代表字母 `'a'` 到 `'z'`。

  返回 ***按字典序最小** 的字符串，该字符串从这棵树的一个叶结点开始，到根结点结束*。

  > 注**：**字符串中任何较短的前缀在 **字典序上** 都是 **较小** 的：
  >
  > - 例如，在字典序上 `"ab"` 比 `"aba"` 要小。叶结点是指没有子结点的结点。 

  节点的叶节点是没有子节点的节点。

   

  **示例 1：**

  **![img](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2019/02/02/tree1.png)**

  ```
  输入：root = [0,1,2,3,4,3,4]
  输出："dba"
  ```

  **示例 2：**

  ![img](https://assets.leetcode.com/uploads/2019/01/30/tree2.png)

  ```
  输入：root = [25,1,3,1,3,0,2]
  输出："adz"
  ```

  **示例 3：**

  ![img](https://assets.leetcode.com/uploads/2019/02/01/tree3.png)

  ```
  输入：root = [2,2,1,null,1,0,null,0]
  输出："abc"
  ```

   

  **提示：**

  - 给定树的结点数在 `[1, 8500]` 范围内
  - `0 <= Node.val <= 25`

## 讲解

这道题目的解法就是先把所有的可能生成的字符串全部找出来，然后一一比较找出来字典序最小的即可，比如样例一中可能的所有字符串有 dba、eba、dca、eca，其中字典序最小的是dba，那么在解决时首先凑出这四个字符串，然后比较就行了。具体的代码实现类似于前序遍历，前序遍历就是在二叉树中，从根节点开始（a），让它跑到它的左右节点，但是在进入前就把根节点a加入到路径中，然后对于它的左右节点b和c，再继续往他们各自的左右子节点传下去即可，即d和e。由于题目要求是从叶结点（即没有左右子节点的最下层的那个结点）开始到根节点，所以生成路径后形成的那一个字符串就需要反转后才是题目要求的，因为按照原本的路线形成的字符串为abd、abe、acd、ace，正好与要求的相反，所以核心的代码如下：
```cpp
class Solution {
public:
    string ans="~";
    void dfs(TreeNode* root,string path){
        if(root==nullptr)return;

        path.push_back(char(root->val+'a'));

        if(root->left==nullptr&&root->right==nullptr){
            string rpath(path.rbegin(),path.rend());
            if(rpath<ans)ans=rpath;
        }else{
            dfs(root->left,path);
            dfs(root->right,path);
        }

        return;
    }
    string smallestFromLeaf(TreeNode* root) {
        if(root==nullptr)return "";
        dfs(root,"");
        return ans;
    }
};
```
对于dfs函数中的path这一参数，对于样例一中的二叉树，它首先为 a，进入左子树后，path参数获取到的是上一个节点添加后的path值a，先添加了b，变成 ab ，然后继续进入左子树，此时这个左子树得到的path值是上一个节点添加后的path值ab，添加d，变为 abd ，此时为叶节点，更新ans为dba，然后回到上一层，上一层的path值为ab没有改变（因为刚才对于path的修改相当于再创造了一个相同的字符串窜path给下一层，而这一层的path一直没有被修改过），以ab进入上一层的b节点处进入右子树，此时获取的path值为上一个节点添加后的path值ab，此时添加e，变为abe，然后与之前更新的ans == dba进行比较，然后回到上一层，上一层的path值为ab没有改变，此时b的左右传递都已结束，则继续返回，此时回到a，path也变回a，然后继续往右走，这样就能完全枚举出所有的可能字符串。
注意虽然需要遍历每一个路径，但是在此处为值传递，即传递一个path副本给下一层，所以下一层的所有改动不会影响这一层本身的path，所以不需要回溯，回溯就相当于遇到一个交叉路口，你又想把所有的路都走一遍，那么你选择一条路之后还需要回到这个交叉路口去走其它没走过的路径。
所以解决这题的核心思路就是暴力解决：把所有可能的字符串找出来，然后找出字典序最小的那一个。

在一开始做的时候，我以为这道题与之前的找出二叉树最小/最大深度相同，就是用递归的思路，假定左右子树的最小字典序的字符串已经知道了，比如样例一中的根结点a的左右子树最小的字符串为db，那么获得了这个最小的字符串后加上根字符即为答案，但是这种思路存在一个很严重的问题：子问题的答案不一定是原问题的答案，意思就是左右子树中的最小字符串加上根字符后不一定是整体的最小字符串，比如说有这样一颗树：根节点为e，其左结点为a，右节点为b，右节点为叶节点，左节点还有一个左节点b，那么对于e这个根节点的左子树为ba，右子树为b，[详细比较步骤：由于**题目**中有说明**字符串中任何较短的前缀在 字典序上 都是 较小 的**,而b为ba的一个前缀，那么这样看b是最小的]，那么加上这个e就是be，但是be是比bae还要大的，因为对于两个字符串的第一个字符都为b，那么在相同的情况下去比较下一个字符，对于两个字符串的第二个字符，a是小于e的，那么bae的字典序就会小于be，因此这种递归的做法是不正确的。因此，对于这种子问题答案不一定能够为整体问题答案的题目，使用这种递归解法是错误的。

如果想要有一点优化的话可以将dfs的path值传递改为传递其地址，这样每一步都共用一个path，那么此时每一层对path的修改都会影响上一层的path内容，所以在结束后需要进行回溯。回溯时在操作完毕后添加path.pop_back();，它的作用是当这一层的所有操作（往左子树传递或者往右子树传递或者更新ans）结束后，需要回到上一层对同一层的其它节点进行操作时及时删除这一个节点带来的影响，比如说当完成第一个分支abd时，此时在d这一节点中path值为abd，现在需要返回b节点往右走，形成abe，那么等回到b时现在的path必须要是ab才能继续，那么就需要在d返回前将abd的末尾d删除再回去，同理，当abd、abe都完成后需要回到根节点，那么ab的末尾b也要删除后才能回到a。
```cpp
class Solution {
public:
    string ans="~";
    void dfs(TreeNode* root,string& path){
        if(root==nullptr)return;

        path.push_back(char(root->val+'a'));

        if(root->left==nullptr&&root->right==nullptr){
            string rpath(path.rbegin(),path.rend());
            if(rpath<ans)ans=rpath;
        }else{
            dfs(root->left,path);
            dfs(root->right,path);
        }

        path.pop_back();
        return;
    }
    string smallestFromLeaf(TreeNode* root) {
        if(root==nullptr)return "";
        string path;
        dfs(root,path);
        return ans;
    }
};
```
对于dfs的优化就是剪枝，剪枝指的是在完整得出一个字符串前就有办法判定它一定不是答案，那么可以提前结束用于优化。对于这道题来说，如果从根节点往叶节点遍历，想要剪枝是比较难的，因为从根节点开始的话先形成的是字符串的后缀，也就是字符串尾部的几个字符，但是在字典序的排序中，是从第一个字符开始一一比较，如果前面有较大的，后面再长也没用，比如说字符串1：z和字符串2：azzzzzzzzzzzzzzzzzz相比较，第一个字符中字符串1的z比字符串2的a大，那么在字典序比较中，字符串1就是大于字符串2的，这也是递归的解法是错误的原因：对于一个字符串加上相同的后缀无法保证字典序会保持相同。因此想要剪枝，就需要从树叶开始往根遍历，这样就能够剪枝了，比如说现在答案为dba，那么在叶节点遇到e时可以直接跳过，因为e大于d了。但是想要从叶子开始往根遍历，需要一次dfs正向遍历，那么不如直接完全枚举。
