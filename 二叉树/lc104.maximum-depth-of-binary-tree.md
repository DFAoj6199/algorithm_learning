# 力扣104.二叉树的最大深度

- 概念：力扣104.二叉树的最大深度

- 给定一个二叉树 `root` ，返回其最大深度。

  二叉树的 **最大深度** 是指从根节点到最远叶子节点的最长路径上的节点数。

   

  **示例 1：**

  ![img](https://assets.leetcode.com/uploads/2020/11/26/tmp-tree.jpg)

   

  ```
  输入：root = [3,9,20,null,null,15,7]
  输出：3
  ```

  **示例 2：**

  ```
  输入：root = [1,null,2]
  输出：2
  ```

   

  **提示：**

  - 树中节点的数量在 `[0, 104]` 区间内。
  - `-100 <= Node.val <= 100`

- 导出时间：2026/8/12 21:38:24

## 讲解

解决这道题首先要知道什么是“递归”。对于一颗二叉树，我们可以把它分为三个部分：根、左子树、右子树，其中两个子树可以分别看作一个整体，我们不需要关心里面的树具体是什么结构。
对于一个节点，如果想要以这个节点为根节点的树有多深的话，我们只需要获得左、右节点中最深的深度，然后加上根节点本身即可，那么在写maxDepth这个函数时，首先要判断当前所在的节点是否为空，如果为空那么就返回0，相当于这个空节点的树高度为0，然后再“假装”maxDepth本身可以获得左右子树的高度并直接拿来用，分别做为maxleft和maxright的值，判断二者最大值返回这个最大值+1即可。在这个过程中，使用maxDepth函数本身就是“递”的过程：不断进入子树，而返回最大值+1就是”归“的过程。
在解题中会忘记返回时+1导致一直返回0而出错，本质上就是子树在返回时根节点也占了一个高度，需要加一后将整体往上“归”。
以示例一[3,9,20,null,null,15,7]为例，当进入根节点3时，我们通过调用本身（假装它能够获得答案）获取左子树的高度1以及右子树的高度2，然后返回最大值2以及根节点本身1，结果为3，就是这个示例的答案了，对于右子树，可以看成以20为根节点，再进行一次上面的操作，可以得到这棵树的高度为2并返回到之前的根节点。

另一种解题的思路为从根节点进入每一个子节点，同时记录此时根节点的高度，进入后将高度+1，同时更新一个全局变量，让它一直为高度的最大值，最终返回这个最大值。
再以示例一为例，首先调用函数进入根节点3，变量传入此节点以及进入此节点的父节点的高度0，进入后节点非空，然后将传入的高度0加一变为1后更新全局变量ans为max(ans,cnt) （全局变量和当前高度的最大值），然后分别调用其左子树节点9和右子树节点20，同时参数传入新的cnt 1，对于9这一节点，cnt+1变为2，然后更新ans为2，同时继续调用其左右节点，由于为空，直接返回；对于节点值为20的这一节点，也是cnt+1为2，此时ans也为2，所以ans仍为2，然后继续调用，传参时cnt都为2；然后对于其左右子树，cnt都为2，加一后为3，则更新后ans为3，再调用后左右子树都为空，则直接返回，最终ans为3

## 代码

``` cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int ans=0;
    int maxDepth(TreeNode* root) {
        f(root,0);
        return ans;
    }

    void f(TreeNode* root,int cnt){
        if(root==nullptr)return;
        cnt++;
        ans = max(cnt, ans);
        f(root->left,cnt);
        f(root->right,cnt);
        return;
    }
};
```

``` cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;

        int maxleft = maxDepth(root->left);
        int maxright = maxDepth(root->right);

        return max(maxleft, maxright) + 1;
    }
};
```
